# DealRelay YC Demo Prototype

Local seeded demo for: **commercial promise control for complex B2B partnerships**.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints.

## 60–90 second demo script

1. Start on hero: “Prevent unsupported customer promises before they become post-sale problems.”
2. Show transcript + proposal input for a Brazil partnership deal.
3. Click Extract: DealRelay finds explicit and implied commitments and explains the high Promise Risk Score.
4. Click Route: Product, Finance, Legal, Delivery, CS all work on one shared deal record.
5. Click Transform: centerpiece before/after. Original promise, internal decisions, final approved wording.
6. Click Handoff: CS receives approved commitments and risk context.

## Why it is multiplayer AI

The shared agent cannot finish the job alone. It needs Product readiness, Finance policy, Legal approval, Delivery feasibility, and CS handoff context preserved in one deal record.
